## Earlier release

Version **1.0.0** (2026-08-31) is the code-only release of the earlier v4 model, which corresponds to the corrected-input evidence freeze dated 2026-08-29. Its code remains in this checkout under `models/v4/`, `scripts/v4/` and `scripts/advanced/`, and its tag and release notes are unchanged:

- Release: https://github.com/LevenkinY/cement-turnover-ccs/releases/tag/v1.0.0
- Citation: LevenkinY. *Capacity turnover and CCS planning in China's cement sector: code*. Version 1.0.0. GitHub; 2026. https://github.com/LevenkinY/cement-turnover-ccs/releases/tag/v1.0.0.

Because the two versions are different model generations, cite the version that matches the numbers being reproduced. The v1.0.0 model is not the source of the current manuscript's results.
